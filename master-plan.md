# master-plan.md

## Project Goal

Clarity is one single app that combines personal finance with a smart assistant called Rex. The financial part and Rex must feel like one product, not two separate things. Rex must have access to the same accounts, transactions, budgets, goals, and people that the user talks about.

## Core Features

- Connect bank accounts using Plaid
- Show accounts, balances, and transaction history
- Budgets and goal tracking
- Rex voice assistant and chat
- Memory system that remembers people, context, preferences, and goals
- Full dark theme across the entire app

## Key Rules

- Everything must use the same financial data - Dashboard, Budgets, Transactions, and Rex all read from the same place.
- Rex must follow the real financial numbers, not guess.
- Full dark theme on every screen, no exceptions.
- Rex must ask for confirmation before making important changes.
- Keep the design clean, calm, and easy to read.

This file is the main source of truth for the project. All other files and code must follow this plan.
