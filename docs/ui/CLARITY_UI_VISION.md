# Clarity UI Vision

## North Star

Clarity should feel like a premium, calm finance app with Rex woven into the
same product. The visual language is minimal, spacious, dark-first, and
icon-led: closer to modern AI voice surfaces and quiet productivity tools than
traditional bank dashboards.

## Principles

- Minimalism first. Remove redundant copy, nested cards, decorative borders,
  and repeated descriptions.
- Use one accent. Teal/cyan is the product accent; bright blues are not part of
  the current visual direction.
- Keep dark mode primary. Backgrounds should be near-black with soft graphite
  surfaces and only enough depth to separate content.
- Let finance semantics stay semantic. Income, spending, danger, and success
  use their own restrained colors instead of the brand accent.
- Prefer icon, label, value. Rows should communicate quickly without extra
  explanatory text.
- Preserve product trust. Visual polish must not change Plaid, Supabase, Rex
  Brain, voice backend, navigation, or data flows.

## Surface Language

Surfaces should be quiet. Use flat fills, subtle dividers, and generous spacing.
Borders are opt-in and neutral. Glows and gradients are reserved for rare
moments where they improve hierarchy, not as a default card treatment.

Buttons should be ghost or outline unless they are the primary action in the
current view. Filled actions use restrained teal, not saturated blue.

## Screen Direction

Dashboard cash flow is the hero. Transaction rows should be minimal: merchant,
amount, and a small category pill.

Accounts should read like a clean financial list, not a stack of heavy cards.
Connection and sync status stay visible but visually calm.

Budgets should emphasize current performance and category progress. Management
details belong in the sheet, not in every row.

Assistant should feel like Rex is part of Clarity, not a second app. The tab
shell stays functional but loses repeated marketing copy and heavy framed
headers.

Profile is a quiet settings surface with clear account, Rex/voice, appearance,
and session actions.

Voice is an overlay-like, icon-led experience with minimal text, visible
controls, and preserved accessibility.

## Non-Goals

- No backend changes.
- No Plaid or Supabase behavior changes.
- No Rex Brain, prompt, memory, recall, or finance truth changes.
- No navigation or data model changes unless explicitly planned separately.
- No new decorative copy, cards, or borders.
