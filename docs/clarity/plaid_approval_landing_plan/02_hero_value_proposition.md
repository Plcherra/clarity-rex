# File 02 - Hero & Value Proposition

Goal: make the first viewport communicate Clarity clearly: a personal AI financial co-pilot with Rex inside, built around user consent and privacy.

## Phase 1 - Core Positioning

Goal: define the one-sentence product promise.

Status: Complete. The core product promise, approved headline direction, supporting copy direction, Rex naming rules, and financial advice boundaries are captured in `hero_core_positioning.md`.

Files to modify/create:
- Landing page copy file

Acceptance Criteria:
- Headline says Clarity is a personal AI financial co-pilot.
- Rex is introduced as the assistant inside Clarity.
- Copy avoids guarantees like "fix your finances."

Risks & Mitigations:
- Risk: product sounds like regulated financial advice.
- Mitigation: position as organization, insight, and coaching support.

Effort: Small.

## Phase 2 - Primary CTA

Goal: decide the launch CTA.

Status: Complete. The primary/secondary CTA labels, targets, forbidden CTA copy, mobile/desktop requirements, accessibility rules, and Plaid review boundaries are captured in `hero_cta_contract.md`.

Files to modify/create:
- Hero CTA component

Acceptance Criteria:
- Primary CTA is "Join the beta" or "Request access."
- Secondary CTA is "See how data is handled" or "Read privacy."
- CTA works on mobile and desktop.

Risks & Mitigations:
- Risk: CTA implies instant Plaid production access.
- Mitigation: use beta/request language.

Effort: Small.

## Phase 3 - Trust Subcopy

Effort: Small.
