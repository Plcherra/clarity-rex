# Clarity Hero Visual Direction

Status: File 02 Phase 4 visual direction approved for initial landing launch.

Purpose: define the hero visual approach so the first viewport feels credible, product-led, and Plaid-review friendly without exposing personal financial data.

## Visual Strategy

The hero should use product proof, not abstract decoration.

Preferred visual direction:

- A polished mobile app screenshot or mock showing Clarity's dashboard, budgets, or Rex assistant.
- Synthetic or staged data only.
- A clean device frame or simple product crop.
- Enough visible UI detail for reviewers to understand the product.

Avoid:

- Pure abstract gradients.
- Decorative orb/bokeh backgrounds.
- Generic stock finance photos.
- Fake charts that do not map to the product.
- Oversized lifestyle imagery that hides the actual app.

## Recommended Hero Visual

Preferred v1 hero visual:

- One mobile app mock showing Clarity's financial overview plus a small Rex context cue.

Acceptable alternatives:

- Dashboard/budget screenshot only.
- Rex assistant screenshot only if financial context is still explained in nearby copy.
- Two-screen product mock only if it remains readable on mobile.

Do not use more than two phone screenshots in the hero.

## Data Safety Rules

Hero visuals must not show:

- Real names.
- Real account balances.
- Real account numbers.
- Real emails.
- Real merchant history.
- Real transaction dates from a user's account.
- Sensitive memory or goals content.

Approved data sources:

- Synthetic demo account.
- Staged screenshot.
- Redacted screenshot where no private financial data remains.

## Plaid Review Alignment

The hero visual should help reviewers understand:

- Clarity is a real product experience.
- The product focuses on transactions, budgets, spending context, and Rex assistance.
- The public site is not launching Plaid Link.
- The landing page does not collect bank credentials.

Do not show:

- Plaid Link UI in the hero.
- Bank login screens.
- Institution logos unless usage is reviewed.
- Any claim that Plaid sponsors or endorses Clarity.

## Mobile Requirements

- The hero visual must not push the headline and primary CTA entirely below the first viewport.
- If the visual appears above the fold on mobile, it should be compact and readable.
- If the visual appears below copy on mobile, the next trust section should still peek where practical.
- Text inside screenshots should remain legible or the screenshot should be used as product atmosphere only with separate readable page copy.

## Desktop Requirements

- The visual should support the headline, not overpower it.
- Avoid split layouts that make the visual look like a separate marketing card disconnected from the message.
- Keep the hero focused on Clarity's actual product surface.
- Decorative background treatment should be subtle and not replace product imagery.

## Asset Preparation Rules

Before implementation:

- Create or select screenshots from a staged/synthetic account.
- Document screenshot source and date in the screenshot policy from File 03.
- Export optimized image sizes for desktop and mobile.
- Include meaningful alt text.
- Review every visible number, merchant, name, and memory item before publishing.

## Acceptance Checklist

- Hero uses real/synthetic app UI or a clean product mock.
- No decorative-only abstract hero.
- No personal account data is visible.
- Visual supports Clarity as the product and Rex as the assistant.
- Visual does not imply Plaid endorsement or launch Plaid Link.
