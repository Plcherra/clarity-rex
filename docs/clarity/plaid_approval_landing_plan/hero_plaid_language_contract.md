# Clarity Hero Plaid Integration Language Contract

Status: File 02 Phase 6 Plaid integration language approved for initial landing launch.

Purpose: define how Plaid may be mentioned in or near the hero without implying endorsement, sponsorship, production approval, or unsupported security claims.

## Hero Plaid Language Rule

Plaid should not be the main hero message.

The hero should lead with:

- Clarity as the product.
- Rex as the assistant inside Clarity.
- Transactions, budgets, spending context, and decisions.
- User control and data handling.

Plaid may appear as a supporting trust/data point only.

## Approved Short Plaid Mentions

Approved wording:

- `Account connection through Plaid, with your permission.`
- `Connect supported financial accounts through Plaid when you choose.`
- `Clarity uses Plaid to help users connect financial accounts with permission.`

Preferred hero-adjacent version:

> Account connection through Plaid, with your permission.

## Dedicated Section Wording

The deeper home-page consent section should use the longer wording from `plaid_consent_placement_contract.md`.

Hero copy should link or point to that section instead of trying to explain every detail above the fold.

Recommended nearby link:

- `See how data is handled`

Recommended target:

- `/#data-consent`

Fallback targets:

- `/privacy`
- `/security`

## Words To Avoid

Avoid:

- `Plaid-approved`
- `Plaid-backed`
- `Plaid-certified`
- `Plaid partner`
- `partnered with Plaid`
- `Plaid sponsors Clarity`
- `Plaid powers all of Clarity`
- `securely connect` unless final reviewed copy supports that exact phrase
- `bank-grade`
- `financial advisor powered by Plaid`

## Safe Explanation Pattern

When explaining Plaid in short copy, follow this pattern:

1. User chooses to connect.
2. Plaid helps facilitate the connection.
3. Clarity uses authorized data for product features.
4. User can disconnect or request deletion.

Example:

> When you choose to connect an account, Clarity uses Plaid to help establish the connection. Clarity uses authorized financial context for transaction organization, budgets, insights, and Rex context.

## Placement Rules

Plaid language may appear in:

- Trust bar.
- Hero trust subcopy if space allows.
- Dedicated consent section.
- FAQ.
- Privacy Policy.
- Security page.

Plaid language should not appear in:

- Primary CTA label.
- Product name.
- Main headline unless specifically reviewed.
- Hero visual labels.

## Compliance Boundary

Plaid wording must not imply:

- Clarity already has production approval unless true and reviewed.
- Plaid endorses Clarity.
- Plaid is responsible for Rex responses.
- Plaid provides Clarity's AI features.
- The public site can connect bank accounts directly.

## Acceptance Checklist

- Plaid is mentioned factually and neutrally.
- Copy says users connect accounts with permission.
- Copy avoids sponsorship, endorsement, and approval claims.
- Copy links to data handling details.
- Copy does not make Plaid the main product story.
