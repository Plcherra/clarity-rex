# Sitemap And Robots

Status: File 09 Phase 4 sitemap and robots pass complete.

## Scope

This pass makes the public Clarity landing and compliance routes discoverable while keeping app-only, form result, staging, and future private routes out of crawler entry points.

## Implemented Files

- `apps/web/src/pages/sitemap.xml.ts`
- `apps/web/src/pages/robots.txt.ts`

Both files are generated by Astro during the static build so they share the same centralized production domain and public route list as the rest of the site.

## Public Sitemap Routes

The sitemap includes only:

- `https://goclarity.app/`
- `https://goclarity.app/privacy`
- `https://goclarity.app/terms`
- `https://goclarity.app/security`
- `https://goclarity.app/data-deletion`
- `https://goclarity.app/contact`

The sitemap intentionally excludes:

- Form success and error pages.
- App dashboard routes.
- Internal review routes.
- Any private or future authenticated web app paths.

## Robots Rules

`robots.txt` allows public crawling and points crawlers to:

- `https://goclarity.app/sitemap.xml`

No private route is advertised.

## Domain Rule

The public domain is `https://goclarity.app`.

This matches the current deployment direction and is sourced from the central product metadata to reduce future drift.

- Robots file points to the production sitemap.
