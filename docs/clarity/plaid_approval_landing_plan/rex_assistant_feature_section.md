# Clarity Rex Assistant Feature Section

Status: File 03 Phase 4 Rex assistant section approved for initial landing launch.

Purpose: introduce Rex as the assistant inside Clarity in a way that feels useful, trustworthy, and clearly bounded for Plaid reviewers and future users.

## Section Role

The Rex feature section should explain how Rex helps users work with Clarity's financial context.

Rex should be presented as:

- The AI assistant inside Clarity.
- A way to ask questions about spending, budgets, goals, and saved context.
- A chat and voice interface for understanding patterns and tradeoffs.
- A support layer over user-authorized Clarity data.

Rex should not be presented as:

- The product name.
- A bank connection provider.
- A financial advisor.
- An autonomous money manager.
- A replacement for user judgment.

## Recommended Section Title

Preferred:

- `Ask Rex about your money context`

Acceptable alternatives:

- `Rex helps explain what Clarity sees`
- `Chat with Rex about spending, budgets, and goals`
- `A financial co-pilot you can talk to`

Avoid:

- `Rex manages your finances`
- `Rex gives financial advice`
- `Connect your bank to Rex`
- `Rex knows everything about your money`

## Recommended Section Copy

Preferred short copy:

> Rex is the AI assistant inside Clarity. Ask Rex about spending patterns, budgets, goals, and saved context so you can review decisions with more context.

Optional voice-support copy:

> Use chat for detailed questions or voice when you want a faster, hands-free conversation.

Optional memory/context copy:

> Rex can use approved Clarity context to make conversations more useful over time.

## Feature Bullets

Recommended bullets:

- Ask questions about spending, budgets, and goals.
- Review patterns using user-authorized Clarity context.
- Use chat or voice depending on the moment.
- Keep user-approved context available for more personal answers.

## Data And Privacy Boundaries

Rex copy must say or imply:

- Rex works inside Clarity.
- Rex uses Clarity context that comes from user-authorized product data.
- Users remain responsible for financial decisions.
- Memory/context should be approved, controlled, or reviewable by the user.

Rex copy must not say or imply:

- Rex connects directly to banks.
- Rex can access accounts outside Clarity's authorized data.
- Rex continuously listens.
- Rex records all conversations by default.
- Rex makes financial decisions for the user.
- Rex provides regulated financial, investment, tax, or legal advice.

## Screenshot Guidance

Rex screenshots are approved only if they are staged and privacy-safe.

Allowed screenshot concepts:

- A staged Rex chat about a synthetic budget.
- A staged Rex chat about a synthetic spending pattern.
- A staged assistant screen with no private memory or goal content.

Conditional screenshot concepts:

- Voice state screenshot, only if voice UI is stable and copy does not imply continuous listening.
- Memory/goals-adjacent Rex screenshot, only if raw labels and private content are absent.

Do not show:

- Real chat history.
- Real financial details.
- Private memories.
- Raw memory labels.
- Voice error states.
- Debug routing or brain metadata.

## Plaid Review Alignment

This section should help Plaid reviewers understand:

- Why Clarity uses connected transaction/account context.
- How that context supports the Rex assistant experience.
- That account connection is user-authorized.
- That Rex is not an independent bank-access system.

## Acceptance Checklist

- Explains Rex chat, voice, and context-aware help.
- Describes Rex as the assistant inside Clarity.
- Does not claim Rex has direct bank access outside user-authorized Clarity context.
- Includes privacy-aware language.
- Avoids regulated advice and autonomous money-management claims.
