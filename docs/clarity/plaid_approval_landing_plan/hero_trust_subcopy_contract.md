# Clarity Hero Trust Subcopy Contract

Status: File 02 Phase 3 trust subcopy approved for initial landing launch.

Purpose: add a compact trust layer under the hero promise so users and Plaid reviewers immediately understand that Clarity is consent-based, privacy-minded, and not asking for sensitive data on the public page.

## Placement

Hero trust subcopy should appear near the primary and secondary CTAs, before the next section.

It can be presented as:

- One short paragraph.
- Three compact trust bullets.
- A small trust strip below the CTA row.

The trust subcopy must not replace the deeper Plaid/data consent section.

## Preferred Trust Subcopy

Preferred one-paragraph version:

> Connect accounts only when you choose. Clarity uses your authorized financial context to organize spending and budgets, with clear paths to disconnect accounts or request deletion.

Preferred bullet version:

- User-authorized account connection.
- Financial context used for organization, budgets, and insights.
- Clear disconnect and data deletion paths.

## Required Meaning

Hero trust subcopy must communicate:

- The user controls whether account connection happens.
- Connected financial context is used to support organization, budgets, and insights.
- Users can disconnect accounts.
- Users can request data deletion.

## Optional Supporting Line

If the hero has room, this line may appear near the secondary CTA:

> Review how Clarity handles connected account data before requesting access.

## Copy Boundaries

Allowed language:

- `user-authorized`
- `with your permission`
- `financial context`
- `disconnect`
- `request deletion`
- `data handling`
- `privacy`
- `security`

Avoid language:

- `bank-grade`
- `military-grade`
- `never stores financial data`
- `Plaid-approved`
- `Plaid-backed`
- `guaranteed`
- `automatic financial advice`

## Plaid Mention Rule

The hero trust subcopy may mention Plaid only if the wording remains factual and short.

Approved Plaid mention:

> Account connection through Plaid, with your permission.

Avoid making Plaid the focus of the hero. The deeper explanation belongs in the consent section and FAQ.

## Mobile Requirements

- Trust subcopy should fit in one or two short lines when possible.
- If using bullets, no more than three should appear in the hero.
- Trust text should not push the next section completely out of view on common mobile screens.
- Text must not be smaller than normal readable supporting copy.

## Accessibility Requirements

- If bullets are used, render them as real list items or clearly grouped text.
- Links to Privacy, Security, or Data Deletion must have descriptive text.
- Trust text must meet normal contrast requirements.

## Acceptance Checklist

- Mentions user-controlled or user-authorized account connection.
- Mentions privacy/data handling without unsupported absolute claims.
- Mentions disconnect and deletion paths.
- Does not imply Plaid endorsement.
- Does not duplicate the full consent section.
