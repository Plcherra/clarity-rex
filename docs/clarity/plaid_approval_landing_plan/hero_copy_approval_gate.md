# Clarity Hero Copy Approval Gate

Status: File 02 Phase 8 copy approval gate approved for initial landing launch.

Purpose: lock the hero source-of-truth before broader landing page implementation so later sections do not drift from the product promise, compliance boundaries, or user trust posture.

## Approved Hero Source Of Truth

### Product Name

- Product: `Clarity`
- Assistant: `Rex`
- Approved Rex framing: `Rex, the AI assistant inside Clarity`

### Preferred Headline

> Your personal AI financial co-pilot.

### Preferred Supporting Copy

> Clarity brings transactions, budgets, goals, and context together so Rex can help you review patterns, understand tradeoffs, and make decisions with more context.

### Preferred CTA Pair

1. `Request access`
2. `See how data is handled`

### Preferred Trust Subcopy

> Connect accounts only when you choose. Clarity uses your authorized financial context to organize spending and budgets, with clear paths to disconnect accounts or request deletion.

### Preferred Plaid Mention

> Account connection through Plaid, with your permission.

## Final Hero Shape

The implementation should follow this order:

1. Clarity brand/name.
2. Headline.
3. Supporting copy.
4. CTA pair.
5. Trust subcopy.
6. Product visual or next-section peek.

This order can adapt responsively, but the headline and CTA must not be buried below the visual.

## Approval Checklist

Before implementation, confirm:

- Product name is Clarity.
- Rex is described only as the assistant inside Clarity.
- Hero copy does not call Clarity a bank, broker, lender, tax advisor, investment advisor, or financial advisor.
- Hero copy does not promise guaranteed savings or guaranteed outcomes.
- Co-pilot language does not imply Clarity or Rex makes decisions for the user.
- Hero copy does not imply Plaid endorsement, sponsorship, certification, or production approval.
- Hero copy does not launch or imply public Plaid Link access.
- CTA language uses request/beta framing.
- Data-handling CTA is present.
- Trust subcopy mentions permission/user control.
- Disconnect/deletion language appears in or near the hero.
